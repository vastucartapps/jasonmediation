# Gaming & Interactive Applications Portfolio

> Directory for web-based games, browser interactive tools, and cross-platform mobile adaptations (Android & iOS).

---

## 🎮 Portfolio Structure

- [`Web/`](./Web/): High-performance browser games, HTML5 Canvas, WebGL, Three.js 3D experiences, and casual puzzle/simulation web applications.
- [`Mobile/`](./Mobile/): Native and hybrid mobile application wrappers:
  - [`Mobile/Android/`](./Mobile/Android/): APK / Android App Bundles (AAB) built via React Native, Capacitor, or Flutter.
  - [`Mobile/iOS/`](./Mobile/iOS/): Xcode / iOS deployment packages.

---

## 🚀 Strategy & Monetization Pipeline

1. **Web Games**: Developed first using Next.js / React / Canvas for instant playability, SEO indexing, and ad monetization (AdSense / Mediavine / AdThrive).
2. **Mobile Conversions**: Successful, high-engagement web titles are wrapped and ported to Android (Google Play) and iOS (Apple App Store) with in-app purchases and native push notifications.
